- **Nostr SDK 0.45 migration** — the entire protocol stack moves from nostr-sdk 0.44 to 0.45.4 (nostr 0.45.5, nostr-ndb 0.45/nostrdb 0.9, nwc/nostr-connect/nostr-blossom 0.45, mostro-core 0.14.6):
  - **Web storage rebuilt on SQLite** — the event database moves from IndexedDB (which loaded everything into RAM) to SQLite over OPFS with an IndexedDB-VFS fallback, so history no longer counts against browser memory; opening a second tab transparently uses the fallback with its own cache
  - **Persistent gossip store** — NIP-65 relay lists learned by the gossip engine now survive restarts (SQLite-backed on all platforms), making DMs and outbox fetches faster on a cold start
  - **Client rebuilds on login/logout** — the SDK no longer allows attaching a signer at runtime, so the client is rebuilt around your signer while keeping the same database and relay knowledge; NIP-42 relay authentication now works for extension, remote (NIP-46) and Android (NIP-55) signers alike
  - **Publishing is gossip-aware by default** — events carrying p-tags now propagate to the mentioned users' inbox relays via the SDK's routing (replacing a custom propagation task), while the write-relay fast path is preserved
  - Mostro trading benefits from mostro-core 0.14.6: maintenance-mode and unknown refusal reasons are surfaced with clear messages, and gift-wrap chat fixes land for free
  - Private/anonymous zaps (DIP-03) keep working — the crypto is now vendored and owned by nostr.blue after the SDK dropped its NIP-57 helpers
  - Desktop Cashu wallet storage switches from cdk-sqlite to cdk-redb (dependency unification); wallet state restores from your NIP-60 events as designed
  - Badge creation uses the SDK's standardized NIP-58 badge builder
- Emoji keyboard goes worldwide: every ISO 3166-2 subdivision flag (~5,000) joins the picker — US states, Canadian provinces, Japanese prefectures, English counties, French departments and more — placed directly after their country's flag (US → states → DC) with territories sorted last for 13 countries
- Relevance-ranked emoji search: exact matches now surface first — typing "us" puts 🇺🇸 at #1, "ky" or "kentucky" finds the Kentucky flag, "ca" ranks Canada before its states; countries rank above subdivisions and states above counties ("york" → New York before North Yorkshire)
- Search abbreviations work everywhere: find any locale by code or name ("us-ky", "ky", "kentucky", "ontario", "on", "tokyo") even on devices whose fonts can't draw the flag
- Smart flag fallbacks: the app probes your device's emoji font once, flag by flag — flags your system can actually draw (Cayman Islands, Kentucky on Noto) stay in place while unrenderable ones sort to the end of the section with tidy "US-KY"-style text labels, so anonymous black-flag boxes never clutter browsing; search applies the same rule within its relevance ranking, and every locale stays findable by code or name
- The Flags and All tabs now render incrementally as you scroll, keeping the picker fast with thousands of entries — this also fixes infinite scroll on the Linux desktop build, which previously stopped loading after the first page
