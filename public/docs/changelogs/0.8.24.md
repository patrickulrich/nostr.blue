  - **Web storage rebuilt on SQLite** — the event database moves from IndexedDB (which loaded everything into RAM) to SQLite over OPFS with an IndexedDB-VFS fallback, so history no longer counts against browser memory; opening a second tab transparently uses the fallback with its own cache
  - **Persistent gossip store** — NIP-65 relay lists learned by the gossip engine now survive restarts (SQLite-backed on all platforms), making DMs and outbox fetches faster on a cold start
  - **Client rebuilds on login/logout** — the SDK no longer allows attaching a signer at runtime, so the client is rebuilt around your signer while keeping the same database and relay knowledge; NIP-42 relay authentication now works for extension, remote (NIP-46) and Android (NIP-55) signers alike
  - **Publishing is gossip-aware by default** — events carrying p-tags now propagate to the mentioned users' inbox relays via the SDK's routing (replacing a custom propagation task), while the write-relay fast path is preserved
  - Mostro trading benefits from mostro-core 0.14.6: maintenance-mode and unknown refusal reasons are surfaced with clear messages, and gift-wrap chat fixes land for free
  - Private/anonymous zaps (DIP-03) keep working — the crypto is now vendored and owned by nostr.blue after the SDK dropped its NIP-57 helpers
  - Desktop Cashu wallet storage switches from cdk-sqlite to cdk-redb — and the localstore is now actually wired: desktop wallet state persists to `wallet.redb` (previously the native path always failed at IndexedDB construction and recovered via NIP-60 events only)

### Review hardening (PR #382 follow-up)

Stability and correctness fixes from the migration PR review pass:

- **Borrow-across-await panics fixed** — five sites held a Dioxus signal write guard across an `.await` (notification + user-prefs subscription shutdown paths); any concurrent access during the await window panicked with `AlreadyBorrowed`. All guards now drop before awaiting
- **Malformed private-zap payloads can't crash rendering** — a crafted kind-9734 `anon` tag whose `iv` segment decodes to fewer than 16 bytes panicked the zap render path; it now takes the error path. Anonymous zap requests also emit the bare `["anon"]` wire format other NIP-57 clients expect
- **Nest room edits preserve status** — editing a Private room no longer silently republishes it as a public live room, Closed rooms stay closed unless explicitly re-opened, and hosts can edit the title of a scheduled room whose start time already passed
- **Mentions are mentions again** — nostr 0.45 standardizes `mention`-marked e-tags as unmarked, which re-threaded pure mentions as replies (a 0.44→0.45 regression); threading now explicitly skips `mention` markers per NIP-10
- **Empty fetch results return promptly** — zero-result quorum fetches no longer park for the full profile timeout when every relay EOSEs empty within the collection window
- **Live follows replay clamp** — the following feed's realtime `since` is clamped to 10 minutes like the global feed, so one quiet relay can no longer trigger an unbounded backlog replay
- **Progressive feed paint is epoch-guarded** — the deferred tail render is skipped when the feed was switched/reset mid-paint, preventing the old feed's tail from leaking into the new feed
- **Coordinate lookups fully re-validated** — `fetch_event_by_id` now checks kind and author (not just the `d` identifier) against the requested coordinate, so an untrusted relay can't satisfy a lookup with an unrelated event
- **Desktop Cashu wallet storage wired to cdk-redb** — the localstore constructor is now actually used on native builds (previously the redb alias was dead code and desktop wallet operations failed at IndexedDB construction)
- **Unmuting your mic in a nest works again** — `mute()` resets the WebCodecs encoder to unconfigured; `unmute()` now reconfigures it so audio publishing resumes without a reconnect (pre-existing bug surfaced by the review)
- Playlist track resolution bounds its fan-out (8 concurrent lookups instead of one simultaneous REQ per missing track), playlist deletion asks for confirmation (deleting a kind-30003 set removes ALL its bookmarks), rename keeps the NIP-51 `name` tag in sync with `title`, and long single-token plaintext descriptions (bare URLs) render instead of being classified as ciphertext
- Zap-receipt backfills use explicit bounded pagination (1000/page × 3 pages × 2500) instead of `usize::MAX`, and the documented total burst bound is now enforced mid-run
- Profile bulk loads dedupe kind-0 versions newest-wins (one entry per contact, O(n) instead of O(n²))
- Bookmark-set viewer list keys are unique per member (duplicate `"p"` keys could panic debug builds)
- The pre-init subscription fallback applies the same event dedup as the dispatcher (no double `on_event` fires), and the `use_relay_subscription` fallback now also sees DB-cached events
- Client rebuilds are serialized (login racing logout can no longer leak an un-shutdown relay pool on desktop)
- Mint discovery fetches use a new `Discovery` profile (10s window with a 3s collection floor) so sparse NIP-87 relays aren't cut off by fast empty EOSEs
- NIP-55 (Android signer) full-JSON responses are signature-verified before use, and the Cashu wallet snapshot derives its pubkey from the active signer rather than a cache
- Round-4 render probes and chatty info logs removed; Playlist editor row labels key by coordinate so they don't shift after an unresolvable track
